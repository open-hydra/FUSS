# Receding surface on a translating mesh, four blocks (plan 11 stage 2)

The case `../receding/N080` (plan 05 gate 5.3, 80 × 4 cells) cut into 4 × 1 blocks of 20 × 4 cells along x, joined by
type-101 connections. Everything else is the same as the source:
- the same slab, 1273.15 K at the receding face and 273.15 K at the far face;
- the analytic initial profile;
- the `translation` law at v = alpha/d;
- `time-threshold = 200`.

It exists so that the moving mesh can be run on several MPI ranks, and restarted on them (plan 11 §2.3): every
moving-mesh case before it was single-block.

- Block 1 holds the receding face; block 4 holds the far face.
- The three cuts carry 24 records of type 101 (orientation `1 0 0 1`).
- Every value in `INPUT/ic.tec` is the source's own string, so the initial state is bit-identical to N080's.
- `input.ini` keeps only the source's `[FUSS-*]` sections, verbatim.

## Generated by

```
python3 test/tools/split_blocks.py test/moving-mesh/receding/N080 4 1 test/moving-mesh/receding_4blk
```

Run it from the repository root. It rewrites `INPUT/`, `MESH/`, `FUSS.sh` and `input.ini`, and leaves this file and
`verify.py` alone. Do not edit these files. Edit `../receding/generate.py`, regenerate N080, then run the command above
again: regenerating N080 alone leaves this case stale.

## What `verify.py` checks

Run `python3 verify.py [case_dir]` after the solve. It imports the constants and the exact cell average from
`../receding/generate.py`.

`../receding/verify.py` reads zone 1 only. Here `verify.py` assembles the first j-row through every zone of
`OUTPUT/field.tec`, block after block in order of x, each shared node once. The decay-fit window 1 ≤ xi/d ≤ 5 spans
blocks 1 and 2.

- **Decay length.** The fitted decay length must match the closed form Pe/ln(1+Pe) to within 2 %.
- **Pointwise error.** The pointwise error against the exact cell averages must stay within 1.5 (Tw − Tinf)(d_num/d − 1)/e.
- **Convergence order.** This needs the grid family and stays with `../receding/verify.py`.
- **Seams.** Every 101 record pairs a face with its neighbour's. The four corner nodes of the two faces must be written
  alike in `field.tec`. The check is on the 15 significant digits that `field.tec` carries.

## The plan-11 gates

- This case at 4 MPI ranks against itself at 1 rank: `run_regression.sh -m 4 -c test/moving-mesh/receding_4blk` against
  `-m 1`. The manifests must be identical.
- The restart gate at 4 ranks, `run_restart_gate.sh -m 4`. A restarted 4-rank run must match the straight one within
  `REL_TOL` 1e-11 (plan 11 §2.3, §2.5).

`run_regression.sh` without `-c` finds this case through its `FUSS.sh`. A full-suite manifest therefore has three rows more
than `test/baseline/manifest.txt` until the baseline is re-recorded.
