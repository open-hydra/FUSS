# Free stream on a moving mesh, four blocks (plan 11 stage 2)

The case `../freestream` (plan 05 gate 5.1) cut into 2 × 2 blocks: the same 60 × 40 mesh, the same uniform 273.15 K, the
same adiabatic walls and the same `prescribed` motion, now as four 30 × 20 blocks joined by type-101 connections. It exists
so that the moving mesh can be run on several MPI ranks: every moving-mesh case before it was single-block.

- Blocks are numbered row-major, b = 1 + bi + 2 bj: block 1 is the low-x, low-y corner, block 2 is beside it along x,
  blocks 3 and 4 sit above them.
- The cut faces carry 200 records of type 101 (orientation `1 0 0 1`).
- Every value in `INPUT/ic.tec` is the source's own string, so the initial state is bit-identical to `../freestream`'s.
- `input.ini` keeps only the source's `[FUSS-*]` sections, verbatim.

## Generated by

```
python3 test/tools/split_blocks.py test/moving-mesh/freestream 2 2 test/moving-mesh/freestream_4blk
```

Run it from the repository root. It rewrites `INPUT/`, `MESH/`, `FUSS.sh` and `input.ini`, and leaves this file and
`verify.py` alone. Edit the source case, not these files.

## What `verify.py` checks

Run `python3 verify.py [case_dir]` after the solve.

- **Free stream.** This is `../freestream/verify.py`'s check, on every zone of `OUTPUT/field.tec`: max |T − T0| and
  max − min below 1e-9 K. That script reads zone 1 only.
- **Seams.** Every 101 record pairs a face with its neighbour's. The four corner nodes of the two faces must be written
  alike in `field.tec`. The check is on the 15 significant digits that `field.tec` carries.

## Measured on 2026-10-16

Conditions:
- frozen `bin/FUSS` md5 `1280f3f6`, `OMP_NUM_THREADS=1`;
- each case copied to a scratch directory with `MASTERDIR` set to the frozen root, then `./FUSS.sh -p 1 solve`.

| quantity | value |
|---|---|
| set-up block of the log | Blocks 4, Cells 2400, Boundary faces 5200, Connection 200, Viscous wall 200 |
| `verify.py` | PASS: max \|T − T0\| = 9.663e-13 K (the unsplit case: 9.663e-13 K); seams 2400 coordinate pairs, 0 differ |
| T vs `../freestream`, cell by cell (`field.tec`) | max\|a−b\|/max\|a\| = 3.5e-15 (9.7e-13 K: one 15-digit quantum at 273 K, in 1 of 2400 cells) |
| x, y, z vs `../freestream`, node by node (`field.tec`) | identical (5208/5208 node entries), SOLUTIONTIME identical (247.853859278717 s) |
| full precision, from a scratch `sol-format = vtk raw` rerun¹ | T rel 6.2e-16 (2348/2400 cells bit-identical); x, y, z bit-identical; shared seam nodes BITWISE equal (2400 pairs) |
| determinism | a second run: `field.tec`, `wall.tec`, `residual-history.dat` md5-identical |
| solver time | 4.0 s (the unsplit case: 2.5–2.8 s), on a shared host |

¹ The `vtk raw` rerun was checked against the ASCII run first: every double it wrote, rounded to 15 significant digits,
equals the ASCII value (32424 values).

In that build the VTK *wall* writer fails after the field files are written: SIGSEGV here, in `receding/N080`, in
`receding_4blk` and in `conjugate_two_layer`, and a hang in `conservation_4blk`. Of the cases tried, only the unsplit
`freestream` completed. The field files are complete in every case.

The comparison maps each block's cells and nodes back to the unsplit indices:
- block (bi, bj) cell (i, j, k) is unsplit cell (30 bi + i, 20 bj + j, k);
- a node shared by two or four blocks is compared in every block that holds it.

Agreement is not bitwise: a 101 interface rounds differently from an interior face.

## The plan-11 gate

The gate is this case at 4 MPI ranks against itself at 1 rank: `run_regression.sh -m 4 -c test/moving-mesh/freestream_4blk`
against `-m 1`. The manifests must be identical (plan 11 §2.5).

`run_regression.sh` without `-c` finds this case through its `FUSS.sh`. A full-suite manifest therefore has three rows more
than `test/baseline/manifest.txt` until the baseline is re-recorded.
