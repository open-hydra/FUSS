# Receding conjugate two-layer slab (plan 08 §2.3 R5, stage B)

Generated by `generate.py` (run it here) from `../../numerics-features/conjugate_two_layer`:
- two blocks along x, 20 + 5 cells over 0.1 + 0.1 m, so dx2/dx1 = 4;
- layerA (k 50) and layerB (k 5), the legacy material path, no pyrolysis.

Block 1's hot end is the ablating wall BC 306 in kinematic mode:
- line 2: `0.0, 300.0, none, env_r5.dat`;
- chemistry off, hconv 1000 W/m²/K, T_edge 1000 K, so the BC 303 kernel applies.

It recedes at the TEST ONLY `sdot-override` of 1e-5 m/s under `law = nodeshift`. Block 1 compresses uniformly toward its pinned
face, the 101 interface; block 2 does not move. 200 steps (12.5 s) take the surface in by 0.125 mm.

## What it checks (`verify.py`, `run_physics_gates.sh -c conjugate_receding`)

- **(pair)** At every solution output, the flux each 101 face put into the residual cancels its partner's. The flux comes
  from `[FUSS-Ablation] dump-interface-flux`, written to `OUTPUT/interface-flux.txt`. The bound is
  max |q₁ + q₂| / q_scale ≤ 1e-12, with q_scale = 2 k₁ A T_ref / dx₁ = 1000 W. Measured 2026-10-13: 8.3e-17.
  - Why it can fail: the faces cancel only while `bc%Mg` holds the current metric of block 1's compressed interface cells,
    which `Update_Mesh` rebuilds after every move.
  - The gate's red control runs a copy with `[FUSS-MeshMotion] skip-bc-metrics-refresh = true`; it measures 8.1e-10 and
    must fail.
  - The plan normalised by max|q|. That is unusable early on: the interface flux is then ~3e-7 W, a difference of
    temperatures that agree to 7 digits, and even the correct run pairs only to 1e-7 of it.
- **(moved)** The mesh really moved:
  - block 1's outer face sits at x = s_total (from `bc306-state.dat`, to the 15 digits of `field.tec`);
  - its lines compress uniformly (cell-size spread 2e-16 m);
  - the interface nodes and block 2 do not move.
