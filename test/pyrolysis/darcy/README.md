# Type-2 (Darcy) Gas Closure

The physics, the reference solutions and the results are on the V&V page:
[Type-2 (Darcy) Gas Closure: Exact and Analytic Benchmarks](../../../docs/vv/darcy-exact.md).

Every case switches on `[FUSS-Pyrolysis] gas-closure = type2` and a `[FUSS-Darcy]` section; most run
on frozen or kinetics-stripped tables, generated by `tools/make_darcy_case.py` (1-D/2-D cases) or
`tools/make_case.py --type2` (the 0-D and ATC2 pairs) — see each case's `input.ini` header for the
exact command.

## Cases

| Case | What it proves | Verifier |
|---|---|---|
| `sealed_nosource` | all faces impermeable, no source: `p` stays at `p-init` and every flux and velocity is exactly 0 | `verify.py` |
| `mass_balance_1d` | steady gas mass balance `mdot(x) = pi x` at every face, time-accurate; `mass_balance_1d_2x` is the same line cut into 1×2 blocks | `verify.py` |
| `sealed_profile/N020` … `N160` | the closed-form steady pressure profile `p^2 = p_w^2 + (pi R T mu/(W K))(L^2 - x^2)`, observed order ≈ 1.9–2.0 | `verify.py` (on the parent) |
| `sealed_profile` + Klinkenberg | the same grids with `klinkenberg = true`: `(p+b)^2` obeys the plain equation | `verify_klinkenberg.py` |
| `tensor_linear_2d` | a 45° rotated orthotropic `K` on the exact field `p^2 = p0^2 + a x`: `|u_y|/|u_x| = K_yx/K_xx`; `tensor_linear_2d_2x2` is the same square cut into 2×2 blocks | `verify.py` |
| `periodic_static`, `periodic_static1` | one sector of a six-sector helical wall under a periodic pair (BC 201), `gas-closure = type2`, static mesh, against the full ring built with ordinary connections | checked by the gate script directly (no case `verify.py`) |
| `adiabatic0d_type2`, `heated0d_type2` | the 0-D cases of `../adiabatic0d/`, `../heated0d/` under type 2 (both faces open at `p-wall`, `K = 1e-7` m²) against the exact type-2 ODE | `verify.py` (calls the type-1 case's own `verify.py`, which detects the closure) |
| `ATC2-chemistryOff-type2` | Ablation Test Case 2 chemistry off under type 2 against the same PATO run as `../ATC2-chemistryOff/`, with `p` probed | `verify.py` |

## Check

Each case's own `verify.py` (or `verify_klinkenberg.py`) reads `OUTPUT/field.tec` and `OUTPUT/darcy.txt`
and compares with the closed-form or reference solution stated on the V&V page; `FUSS_GATE_SELFTEST=1`
zeroes the tolerances. `periodic_static`/`periodic_static1` have no `verify.py` of their own: the gate
script (`periodic_gate` in `run_physics_gates.sh`) builds the reference ring and the symmetry-face
control itself and compares `T`, `p_pg` directly.

## Run

```bash
cd test/pyrolysis/darcy/<case>
./FUSS.sh solve && python3 verify.py
# sealed_profile (and its Klinkenberg variant): run N020, N040, N080, N160, then verify.py
# (or verify_klinkenberg.py) from test/pyrolysis/darcy/sealed_profile, which reads all four
```

Physics gates (also CTest tests, `ctest -L gate`): `test/run_physics_gates.sh -c darcy_sealed_nosource`,
`-c darcy_mass_balance_1d`, `-c darcy_sealed_profile`, `-c darcy_klinkenberg`,
`-c darcy_tensor_linear_2d`, `-c darcy_0d`, `-c darcy_atc2_chemistry_off`, `-c periodic_darcy`.
`mass_balance_1d_2x` and `tensor_linear_2d_2x2` are also run by `test/run_mpi_gate.sh` (2 and 4 ranks
against 1); `periodic_static`/`periodic_static1` by `test/run_mpi_gate.sh` (2 ranks, the periodic pair
split across ranks) and by `test/run_guard_demos.sh` (a periodic face runs under `gas-closure = type2`
when the permeability tensor is invariant under the pair's rotation, and is refused otherwise).
`heated0d_type2` is also a leg of `test/run_restart_gate.sh`.
