# Pyrolysis Energy and Mass Audit

The physics, the reference solution and the results are on the V&V page:
[Pyrolysis Energy and Mass Audit](../../../docs/vv/pyrolysis-energy-audit.md).

## Setup

| Parameter | Value |
|---|---|
| Mesh | one block, 40 cells over 40 mm (1 mm cells) |
| Face 2 | `302`, `Tw_time.dat` (300 → 1644 K in 1 s) |
| Face 1 | adiabatic (`301`, `q = 0`) |
| Material | real TACOT tables |
| Initial condition | 300 K |
| Pyrolysis | `[FUSS-Pyrolysis] gas-closure = type1`, `outflow-direction = +i`, `p-gas = 101325.0` |
| Time scheme | RK3, `vnn = 0.25`, time-accurate |
| Integration variables | `cons` |
| Stop | `time-threshold = 10.0` |
| Probes | four, at 0.5, 1.5, 3.5 and 7.5 mm |

Generated by `test/pyrolysis/tools/make_case.py` (`energy_audit`, see the `input.ini` header). The
solver writes `OUTPUT/energy-budget.txt` at every solution output:
`t E_tot M_s Q_out Q_gas_out M_gas_out Q_src`, with `E_tot = Σ V E(T, χ)`, `M_s = Σ V ρ_s`,
`Q_out = ∫ Σ_cells R dt` (conduction + BC + gas advection), `Q_gas_out`/`M_gas_out` the energy and mass
carried out through the outflow face and `Q_src = ∫ Σ qvol V dt`. The accumulators advance with the
scheme's own Runge–Kutta weights, so the balances below are identities of the discrete update.

## Check

`verify.py` checks (no stored FUSS value):

- **energy**: `|E_tot(t) - E_tot(0) + Q_out - Q_src| <= 1e-10 max(|E_tot(0)|, |Q_out|)`;
- **solid mass**: `|M_s(t) - M_s(0) + M_gas_out| <= 1e-10 M_s(0)`;
- **independent state sum**: `E_tot(t)` and `M_s(t)` recomputed from `OUTPUT/field.tec` (`T`, `chi_*`),
  the `INPUT/` tables and cell volumes from the node coordinates, agree with the solver's own columns
  to `1e-10` relative;
- **time-discretisation order**: probe series from two `vnn` refinements, interpolated onto a common
  time grid: the ratio of the successive differences gives the observed order, which must lie in
  [0.8, 1.2] (first order in `dt`; measured 1.163); `FUSS_GATE_SELFTEST=1` empties that window;
- the no-kinetics variant and a 1-vs-8-thread run are additional legs the gate script runs through
  the same `verify.py` (`--vnn025`, `--vnn0125`, `--nokin`, `--p8`).

## Run

```bash
cd test/pyrolysis/energy_audit
./FUSS.sh solve && python3 verify.py
```

Physics gate: `test/run_physics_gates.sh -c pyrolysis` (together with `kinetics_isothermal`,
`adiabatic0d`, `heated0d`, `conduction`, `ATC1` and `ATC2-chemistryOff`; not in CTest). Also a leg of
`test/run_restart_gate.sh` (the reaction state `chi_*` round-trips across a restart) and the base of
the pyrolysis guard demos (`test/run_guard_demos.sh`).
