# Baum & Atreya (2007): Charring Front with Darcy Flow

The physics, the reference solution and the results are on the V&V page:
[Literature Benchmarks of the Pyrolysis and Ablation Models](../../../../docs/vv/pyrolysis-literature.md#baum--atreya-2007-charring-front-with-darcy-flow).

## Setup

| Parameter | Value |
|---|---|
| Mesh | one block, 100 cells over 40 mm (`full_N100`; `full_N100_20blk` splits it into 20×1 blocks) |
| Face (surface) | `302`, held at 1298.16 K from `t = 0`, open at `p_s = 101325` Pa |
| Face (back) | sealed (`301`, `q = 0`) |
| Material | Di Blasi property set: `rho_v = 700`, `rho_c = 140` kg/m³, `k_v = 0.209`, `k_c = 0.071` W/(m·K), `c_v = 1400`, `c_c = 1100` J/(kg·K); zeroth-order decomposition at `Tp = 598.16` K, `A = 0.0329806 /s` |
| Permeability | `K_c = 1e-15` m² (virgin effectively impermeable, `K_v = 1e-20` m²) |
| Pyrolysis | `[FUSS-Pyrolysis] gas-closure = type2`, `[FUSS-Darcy]`, `eps_c = 0.76` (gas storage) |
| Initial condition | 298.16 K |
| Time scheme | RK3, `vnn = 0.25`, time-accurate |
| Stop | `time-threshold = 300` |

Two gas-heat-capacity choices: `c_g = 1475` J/(kg·K) (`full_N100`/`full_N100_20blk`, which makes the
decomposition heat independent of `T`) and `c_g = 0`, the paper's own case run quasi-steady
(`qs_N100`, `quasi-steady = true`, the paper's `beta = 0`). Generated by
`test/pyrolysis/tools/make_baum_atreya.py` (see each case's `input.ini` header); `tools/lit_case.py`
holds the shared writer.

## Check

`verify.py <full-case> [<full-case> ...] [--qs <qs-case>] [--record]` compares each full-mode run
against the Rankine-Hugoniot similarity solution of `tools/darcy_exact.py` (corrected front
condition), averaged over `30 <= t <= t_end`:

- the mass-based front error on the finest grid, and its order on the finest pair;
- the `L2` temperature error (char + preheat);
- `<p^2 - p_s^2>` at the probe nearest 1 mm, against the exact quasi-steady char pressure;
- every full run's gas-mass ledger (an identity, round-off);
- the quasi-steady run's ledger (a one-step bound, not an identity).

Budgets are in `expected.json` beside `verify.py`; `FUSS_GATE_SELFTEST=1` zeroes them.

## Run

```bash
cd test/pyrolysis/lit/baum_atreya2007
(cd full_N100 && ./FUSS.sh solve)
(cd qs_N100 && ./FUSS.sh solve)
python3 verify.py full_N100 --qs qs_N100
```

Physics gate: `test/run_physics_gates.sh -c bench_baum_atreya` (not in CTest; generates and runs
`full_N100`, `full_N200` and the quasi-steady `qs_N100` into a work directory). `qs_N100` is also a
leg of `test/run_restart_gate.sh`.
