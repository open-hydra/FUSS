# Zhang (2010): Three-Code Decomposing Slab

The physics, the reference solution and the results are on the V&V page:
[Literature Benchmarks of the Pyrolysis and Ablation Models](../../../../docs/vv/pyrolysis-literature.md#zhang-2010-three-code-decomposing-slab).

## Setup (`N050`)

| Parameter | Value |
|---|---|
| Mesh | one block, 50 cells over 12.7 mm (even, so the mid-plane falls between two cell centres) |
| Exposed face | `305`, `hconv = 10` W/(m²K), `eps = 1`, `Tref = 773.224566` K (reproduces `q_rad = 25` kW/m² `- sigma eps T_s^4 + h(T_inf - T_s)`), open at `p_s` (type-1 outflow) |
| Unexposed face | adiabatic |
| Material | `rho = 1700 -> 1255` kg/m³, single Arrhenius reaction `A = 5e28 /s`, `E = 3.62e5` J/mol, `n = 4.6`, decomposition heat `Q = -2e5` J/kg at `Tref = 273` K (Henderson-form), `Cp = 1100`, `Cg = 3000` J/(kg·K), `k = 0.30` W/(m·K) |
| Pyrolysis | `[FUSS-Pyrolysis] gas-closure = type1`, `outflow-direction = -i`, `p-gas = 101325.0` |
| Initial condition | 300 K |
| Time scheme | RK3, `vnn = 0.25`, time-accurate |
| Stop | `time-threshold = 2000` |

Virgin and char share `h(T) = Q + Cp(T - Tref)`, so `h_g - h_bar` reproduces the thesis's `h_g - h`
term for term. Generated by `test/pyrolysis/tools/make_zhang2010.py` (see the `input.ini` header).

## Check

`verify.py <case> [--record]` reads the exposed, mid-plane and unexposed temperatures from `wall*.tec`
and the mid-plane probes, and the exposed-face gas mass flux from the first cell's `mdot_pg`, and
compares with the three codes of the thesis, digitized from the vector figures
(`ref/zhang_fig2_2_T.csv`, `ref/zhang_fig2_3_mloss.csv`; provenance in `ref/README.md`):

- for `t > 20` s, `max |T_FUSS - T_MATLAB|` at each of the three planes against that plane's spread of
  the three codes, computed from the digitized curves (4.75, 5.26, 5.10 K; FUSS 3.29, 2.51, 2.08 K);
- the FUSS peak gas mass flux within the three codes' own peak range, and its time within the budget
  of their mean peak time.

The gas-flux window factors (0.95, 1.05) and the 30 s time window are in `expected.json`; they are not
taken from the reference, and the reference's own peak range ([4.4893e-3, 4.5984e-3]) is not met: the
FUSS peak, 4.369e-3, is mesh-converged (N050 and N100 agree to 1e-7) and 2.7 % below the lowest code
(an open finding of plan 17). `FUSS_GATE_SELFTEST=1` zeroes every tolerance.

## Run

```bash
cd test/pyrolysis/lit/zhang2010/N050
./FUSS.sh solve
cd .. && python3 verify.py N050
```

Physics gate: `test/run_physics_gates.sh -c bench_zhang2010` (not in CTest).
