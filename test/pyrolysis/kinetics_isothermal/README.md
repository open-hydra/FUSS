# Isothermal Pyrolysis Kinetics

The physics, the reference solution and the results are on the V&V page:
[Pyrolysis Kinetics and 0-D Decomposition](../../../docs/vv/pyrolysis-kinetics-0d.md).

## Setup

| Parameter | Value |
|---|---|
| Mesh | one block, 4 cells over 4 mm |
| Both i-faces | `302`, held at `T0` |
| Material | the `--isothermal` test tables: `cp`, `h`, `k` constant; `h` and the gas `h_pg` the same linear function of `T`; `eps_g_v = eps_g_c` |
| Initial condition | `T0` |
| Pyrolysis | `[FUSS-Pyrolysis] gas-closure = type1`, `outflow-direction = +i`, `p-gas = 101325.0` |
| Time scheme | RK3, `vnn = 0.25`, time-accurate |
| Integration variables | `cons` |
| Stop | `time-threshold = 30.0`, a field file every second |

| Case | `T0` |
|---|---|
| `T0700` | 700 K |
| `T0900` | 900 K |
| `T1200` | 1200 K |

With the tables above `T` stays exactly at `T0`, so every reaction follows the closed form
`1 - χ(t) = [1 + (m - 1) κ t]^(-1/(m-1))` (`m ≠ 1`) or `1 - χ(t) = exp(-κt)` (`m = 1`), with
`κ = A T0^n exp(-E/(R T0))` above the reaction's threshold. Generated by
`test/pyrolysis/tools/make_case.py --isothermal` (see each case's `input.ini` header).

## Check

On every `OUTPUT/field<i>.tec`, every cell, `verify.py [case_dir]` (default: `T0700`) checks:

- `max |chi_r - chi_exact(t)| <= 1e-8` (the exact propagator; the only error is the Newton tolerance
  on `T` propagated into `κ`);
- `max |T - T0| <= 1e-7` K;
- `rho_s = rho_v - Σ_r eps_I rho_I F_r chi_r` to `1e-10` relative;
- the type-1 line integral: with uniform cells and a uniform state,
  `mdot_pg(s) = s * mdot_pg(1)` along every line, to `1e-12` relative, and `mdot_pg(1) > 0` while any
  `chi_r < 1`.

## Run

```bash
cd test/pyrolysis/kinetics_isothermal
./T0700/FUSS.sh solve && python3 verify.py T0700   # or T0900, T1200
```

Physics gate: `test/run_physics_gates.sh -c pyrolysis` (all three temperatures, together with
`energy_audit`, `adiabatic0d`, `heated0d`, `conduction`, `ATC1` and `ATC2-chemistryOff`; not in
CTest).
