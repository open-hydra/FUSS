# Pure Conduction on the Pyrolysis Path

The physics, the reference solution and the results are on the V&V page:
[Pyrolysis Energy and Mass Audit](../../../docs/vv/pyrolysis-energy-audit.md).

## Setup (`graded100`)

| Parameter | Value |
|---|---|
| Mesh | one block, 100 cells over 0.05 m, graded (ratio 0.1) toward the heated face, as `ATC1` |
| Face 2 (heated) | `302`, `Tw_time.dat` (a step to 1644 K at `t = 0`) |
| Face 1 | adiabatic (`301`, `q = 0`) |
| Material | constant properties: `cp = 1000` J/kg/K, `k = 0.4` W/m/K, `rho_v = 280` kg/m³; the kinetics stripped (`nPyroReac = 0` for every reaction) |
| Initial condition | 298 K |
| Pyrolysis | `[FUSS-Pyrolysis] gas-closure = type1`, `outflow-direction = +i`, `p-gas = 101325.0` (no reactions run) |
| Time scheme | RK3, `vnn = 0.25`, time-accurate |
| Integration variables | `cons` |
| Stop | `time-threshold = 60.0` |
| Probes | two index-position probes bracketing each `ATC1` depth (`probes.json`) |

Pure conduction on the pyrolysis code path, with the reactions stripped so that the result is checked
against the exact slab series (`test/pyrolysis/tools/slab_series.py`) rather than against the
decomposition ODE. Generated by `test/pyrolysis/tools/make_case.py --conduction` (see the `input.ini`
header; `--uniform` for a uniform-mesh companion, not gated here).

## Check

`verify.py [case_dir]` (default: `graded100`) compares every probe, as a cell value at its own
depth, with the exact series solution at the probe times `{0.5, 1, 2, 4, 8, 16, 30}` s:

- `max |T - exact|` over every probe and time `<= TOL_ALL` (1.3 K);
- `|T - exact|` at the 1 mm pair, `t = 1 s`, `<= TOL_1MM_1S` (0.7 K);
- `max |T - exact|` over the pairs at `>= 2 mm` and every time `<= TOL_DEEP` (0.6 K).

The uniform-mesh companion is not gated; it shows second order in space.

## Run

```bash
cd test/pyrolysis/conduction/graded100
./FUSS.sh solve
cd .. && python3 verify.py graded100
```

Physics gate: `test/run_physics_gates.sh -c pyrolysis` (together with `kinetics_isothermal`,
`energy_audit`, `adiabatic0d`, `heated0d`, `ATC1` and `ATC2-chemistryOff`; not in CTest).
