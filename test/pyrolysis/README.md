# Pyrolysis cases (plan 06, phase 2: pyrolysis on a static mesh)

| case | gate | what it proves | run by |
|------|------|----------------|--------|
| `kinetics_isothermal/T0700`, `T0900`, `T1200` | 4.2 | the exact closed-form kinetics at a constant temperature, the chi -> rho_s map and the type-1 line integral (`kinetics_isothermal/verify.py`) | default regression sweep; `run_physics_gates.sh -c pyrolysis` |
| `energy_audit` | 4.3 | discrete energy and solid-mass balances to round-off, the independent state sum, first-order vnn refinement, the no-kinetics variant, 1-vs-8-thread identity (`energy_audit/verify.py`, `expected.json`) | default sweep; physics gate; `run_restart_gate.sh`; base of the pyrolysis guard demos |
| `ATC1` (`.slow`) | 4.4 | Ablation Test Case 1 against FUSS's own Richardson limit f* (100/200/400 graded cells, `expected.json`: f*, observed order, the measured 100-cell error at 46 points; band 1 K); the FIAT reference bundled with PATO (`ATC1/ref`) and the 298 K PATO run are printed, not gated (record `plan-bucket/records/2026-10-08-verification/`) | physics gate |
| `adiabatic0d/T1000` | 4.6 | uniform adiabatic TACOT slab from 1000 K against the exact type-1 decomposition ODE (`tools/ode0d.py`): 0.051 K at vnn 0.5, second order in dt | physics gate, regression |
| `heated0d` | 4.7 | the same slab heated by a volumetric source (`INPUT/st.tec`, 3.75e8 W/m3, ~650 K/s) at vnn 0.00625 = ATC1's step: 0.002 K against the exact ODE; prints the exact type-2 (gas storage) and PATO-table-hbar differences | physics gate, regression |
| `conduction/graded100` | 4.8 | pure conduction on the ATC1 mesh (constant properties, step to 1644 K) against the exact slab series (`tools/slab_series.py`): 1.10 K at 1 mm / 0.5 s, 0.50 K at 1 s, second order in space | physics gate, regression |
| `ATC2-chemistryOff` (`.slow`) | 4.5 | Ablation Test Case 2 chemistry-off against a local PATO run with zero emissivity (`ATC2-chemistryOff/ref`, `edit_pato_case.py`) | physics gate |

Every case was generated by `tools/make_case.py` from the tables `tools/make_tacot_tables.py` writes out of PATO 3.1's
TACOT data (`--isothermal` for the kinetics and conduction cases); regenerate with the commands in each `input.ini` header rather than
editing the generated files. Kinds: `isothermal`, `energy_audit`, `atc1`, `atc2off`, `conduction` (kinetics stripped, step time file,
`--uniform` for equal cells), `adiabatic0d` (`--T0` required, `--qvol Q` adds the source file); `--ncells N` for the ATC meshes
(probe pairs recomputed), `--tend`/`--sol-dtime` overrides. The oracles `tools/ode0d.py` (exact 0-D decomposition ODE from the
case's own tables, three variants: type 1, type 2, type 1 with PATO's table hbar; pure Python) and `tools/slab_series.py` (exact
step-heated slab) are imported by the verify scripts; a Richardson re-anchor of ATC1 is
`make_case.py --ncells 200/400` + `plan-bucket/records/2026-10-08-verification/tools/probes_atc1.py richardson`. The BC 302 time file `Tw_time.dat` lives at the case root (resolved relative to the run
directory): every harness that copies a case copies `*.dat` too.
