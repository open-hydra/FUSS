Every case was generated by `tools/make_case.py` from the tables `tools/make_tacot_tables.py` writes out of PATO 3.1's
TACOT data (`--isothermal` for the kinetics and conduction cases); regenerate with the commands in each `input.ini` header rather than
editing the generated files. Kinds: `isothermal`, `energy_audit`, `atc1`, `atc2off`, `conduction` (kinetics stripped, step time file,
`--uniform` for equal cells), `adiabatic0d` (`--T0` required, `--qvol Q` adds the source file); `--ncells N` for the ATC meshes
(probe pairs recomputed), `--tend`/`--sol-dtime` overrides. The oracles `tools/ode0d.py` (exact 0-D decomposition ODE from the
case's own tables, three variants: type 1, type 2, type 1 with PATO's table hbar; pure Python; every RK4 step on one 1 K
table segment and one on/off state per reaction, events located) and `tools/slab_series.py` (exact step-heated slab) are
imported by the verify scripts; `tools/conv_rule.py` is the convergence rule of every ladder (the error falls on every
rung, the order on the finest pair in [0.8 p, 1.2 p]); `make_case.py --masterdir` writes a case outside the tree (the
gates' extra rungs). The BC 302 time file `Tw_time.dat` lives at the case root (resolved relative to the run
directory): every harness that copies a case copies `*.dat` too.

The 1-D/2-D cases are written by `tools/make_darcy_case.py` (kinds `sealed_nosource`, `mass_balance_1d`, `sealed_profile`,
`tensor_linear_2d`; kinetics always stripped, the gas source is `[FUSS-Darcy] pi-source`) from the table set
`make_tacot_tables.py --solid-isothermal --constant-gas 0.022 4e-5 0` (`--cp-override 1e12` for `sealed_profile`, which freezes
`T`); the 0-D and ATC2 copies by `make_case.py --type2 --permeability K` (`--permeability 1e-7` for the 0-D pair; ATC2 takes
TACOT's `K_v`, `K_c`, which `make_tacot_tables.py` now writes into `pyrolysis.dat`). `tools/darcy_tools.py` holds the readers
the verify scripts share. Each verify script honours `FUSS_GATE_SELFTEST=1`. The solver-health record of plan 07 section 4.5
(tridiag vs pseudo on the ATC2 case) is in `darcy/ATC2-chemistryOff-type2/README.md`.

`exact/tables/` holds the `make_tacot_tables.py --isothermal` set the exact cases start from (`tools/make_exact_case.py --tables`);
`tools/make_baum_atreya.py` and `tools/make_zhang2010.py` write the literature cases from analytic tables (`tools/lit_case.py`).
The gates generate their mesh ladders into the work directory with these generators; the in-tree case of each benchmark is its
coarsest member. No gate compares with a stored FUSS value (plan 17): the exact ladders pass by `tools/conv_rule.py` (each
`expected.json` holds the expected orders only), Zhang's temperatures within the three codes' own spread; every verify honours
`FUSS_GATE_SELFTEST=1`.
