# Pyrolysis cases (plan 06, phase 2: pyrolysis on a static mesh)

| case | gate | what it proves | run by |
|------|------|----------------|--------|
| `kinetics_isothermal/T0700`, `T0900`, `T1200` | 4.2 | the exact closed-form kinetics at a constant temperature, the chi -> rho_s map and the type-1 line integral (`kinetics_isothermal/verify.py`) | default regression sweep; `run_physics_gates.sh -c pyrolysis` |
| `energy_audit` | 4.3 | discrete energy and solid-mass balances to round-off, the independent state sum, first-order vnn refinement, the no-kinetics variant, 1-vs-8-thread identity (`energy_audit/verify.py`, `expected.json`) | default sweep; physics gate; `run_restart_gate.sh`; base of the pyrolysis guard demos |
| `ATC1` (`.slow`) | 4.4 | Ablation Test Case 1 against the FIAT reference bundled with PATO (`ATC1/ref`) | physics gate |
| `ATC2-chemistryOff` (`.slow`) | 4.5 | Ablation Test Case 2 chemistry-off against a local PATO run with zero emissivity (`ATC2-chemistryOff/ref`, `edit_pato_case.py`) | physics gate |

Every case was generated by `tools/make_case.py` from the tables `tools/make_tacot_tables.py` writes out of PATO 3.1's
TACOT data (`--isothermal` for the kinetics cases); regenerate with the commands in each `input.ini` header rather than
editing the generated files. The BC 302 time file `Tw_time.dat` lives at the case root (resolved relative to the run
directory): every harness that copies a case copies `*.dat` too.
