# Ablation Test Case 2, chemistry off

The physics, the reference solution and the results are on the V&V page:
[Pyrolysis Kinetics and 0-D Decomposition](../../../docs/vv/pyrolysis-atc2.md).

## Setup

| Parameter | Value |
|---|---|
| Mesh | same as `ATC1`: one block, 100 cells over 0.05 m, graded toward the heated face |
| Face 2 (heated) | `303`, `hconv = 300` W/m²K, `qrad = 0`, `Tref = 2800` K, from `t = 0` |
| Face 1 | adiabatic (`301`, `q = 0`) |
| Material | real TACOT tables, as `ATC1` |
| Initial condition | 300 K |
| Pyrolysis | `[FUSS-Pyrolysis] gas-closure = type1`, `outflow-direction = +i`, `p-gas = 101325.0` |
| Time scheme | RK3, `vnn = 0.25`, time-accurate |
| Integration variables | `cons` |
| Stop | `time-threshold = 60.0` |
| Probes | six, two index-position probes bracketing each PATO probe depth (`probes.json`) |

A zero re-radiation BC 303 face reduces the surface energy balance to the closed form
$q = h_\text{conv}(T_\text{ref} - T_w)$, which both FUSS and the oracle evaluate. The oracle is PATO
3.1's `tutorials/1D/AblationTestCase_2.x_chemistryOff` run with the virgin/char emissivity columns set
to 0 and `chemistryOn = 0` (`edit_pato_case.py` applies the edits); its probe output is read from
`$FUSS_PATO_ATC2_OUT` when set, else from the bundled `ref/` copy. Generated by
`test/pyrolysis/tools/make_case.py` (`atc2off`, see the `input.ini` header).

## Check

`verify.py` interpolates each probe pair in `x`, then onto PATO's 0.1 s grid in time, and passes when
`max |T_FUSS - T_PATO| <= budget_K` over `t = 0.1..60 s` and the seven depths (`expected.json`).

This case is marked `.slow`: the default regression sweep (`test/run_regression.sh`, no `-a`) skips
it; `run_physics_gates.sh` always runs it.

## Run

```bash
cd test/pyrolysis/ATC2-chemistryOff
./FUSS.sh solve && python3 verify.py
```

Physics gate: `test/run_physics_gates.sh -c pyrolysis` (together with `kinetics_isothermal`,
`energy_audit`, `adiabatic0d`, `heated0d`, `conduction` and `ATC1`; not in CTest). The type-2 twin is
`test/pyrolysis/darcy/ATC2-chemistryOff-type2/`, covered by `test/pyrolysis/darcy/README.md`.
