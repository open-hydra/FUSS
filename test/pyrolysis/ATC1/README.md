# Ablation Test Case 1

The physics, the reference solution and the results are on the V&V page:
[Pyrolysis Kinetics and 0-D Decomposition](../../../docs/vv/pyrolysis-atc1.md).

## Setup

| Parameter | Value |
|---|---|
| Mesh | one block, 100 cells over 0.05 m, graded (ratio 0.1) toward the heated face |
| Face 2 (heated) | `302`, `Tw_time.dat` (298 → 1644 K in 0.1 s, held to 60 s) |
| Face 1 | adiabatic (`301`, `q = 0`) |
| Material | real TACOT tables (`INPUT/pyrolysis.dat`, `virgin.dat`, `char.dat`, `gas.dat`) |
| Initial condition | 298 K |
| Pyrolysis | `[FUSS-Pyrolysis] gas-closure = type1`, `outflow-direction = +i`, `p-gas = 101325.0` |
| Time scheme | RK3, `vnn = 0.25`, time-accurate |
| Integration variables | `cons` |
| Stop | `time-threshold = 60.0` |
| Probes | six, two index-position probes bracketing each FIAT thermocouple depth (`probes.json`) |

`Tw_time.dat` lives at the case root and is resolved relative to the run directory; a harness that
copies the case must copy it too. Generated by `test/pyrolysis/tools/make_case.py` (`atc1`, see the
`input.ini` header) — regenerate with that command rather than editing the files it writes.

## Check

`verify.py` compares every probe pair, linearly interpolated in `x` and then in time, against `f*`,
FUSS's own Richardson extrapolation on 100/200/400 graded cells (`expected.json`): the 100-cell
discretisation error measured against `f*` may move by at most `band_K` from the recorded value. The
FIAT reference bundled with PATO (`ref/FIAT_T.dat`) and a 298 K PATO run are printed for comparison,
not gated.

This case is marked `.slow`: the default regression sweep (`test/run_regression.sh`, no `-a`) skips
it; `run_physics_gates.sh` always runs it.

## Run

```bash
cd test/pyrolysis/ATC1
./FUSS.sh solve && python3 verify.py
```

Physics gate: `test/run_physics_gates.sh -c pyrolysis` (together with `kinetics_isothermal`,
`energy_audit`, `adiabatic0d`, `heated0d`, `conduction` and `ATC2-chemistryOff`; not in CTest).
