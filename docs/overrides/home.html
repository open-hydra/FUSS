FUSS

Fourier Un-Steady Solver

Open-source finite-volume solver for steady and time-accurate heat conduction in solids on multi-block structured grids, with temperature-dependent tabulated properties, several materials and per-face boundary conditions.

Features

What the solver does; the Theoretical Guide gives the details

Solid Heat Conduction

Fourier heat equation, steady or time-accurate, with an optional volumetric source. Conductivity, density and heat capacity are tabulated against temperature for each material.

Cell-Centred Finite Volume

Cell-centred finite volumes with two ghost layers per block. Face gradient from the difference across the face plus tangential central differences; face conductivity at the mean of the two cell temperatures. At block connections the interface temperature follows from heat-flux continuity.

Mixed Boundary Conditions

Prescribed heat flux or temperature (constant or from a time table), convection with an imposed flux, radiation, convection plus radiation, adiabatic/symmetry faces, block connections, chimera (overset) blocks, and coupling to the hydra fluid solver.

Accelerated Time Marching

Explicit Euler, RK2 (Heun) and SSP RK3. Steady runs use a local time step, implicit residual smoothing and grid sequencing on coarser levels; time-accurate runs use the global minimum step.

Parallel Execution

OpenMP threads inside the blocks; MPI over whole blocks (largest block first to the least-loaded rank) with ghost and chimera-donor exchange. One process and N ranks write identical files.

Flexible I/O

Tecplot ASCII, Tecplot binary (with TecIO) and VTK output through ORION; wall temperature and heat flux files; point probes; restart from the last solution file.

Build and run

install.sh build fetches the ORION and FiNeR submodules (and FiNeR's own libraries, also submodules), configures CMake and builds bin/FUSS. Each bundled test case carries a FUSS.sh run script.

Installation guide → Quick start
terminal 
# Clone and build
$ git clone https://github.com/open-hydra/FUSS.git
$ cd FUSS && ./install.sh build --compilers=gnu --use-openmp

# Run a simulation
$ cd test/steady-state/temperature_Plate
$ ./FUSS.sh solve
$ python3 verify.py
